- **Recommended Size**: 1200x800px (4:3 aspect ratio)

## Image Format Guidelines
- Format: JPG (for photographs and complex graphics)
- Quality: High resolution (72dpi minimum for web)
- Optimization: Compressed for fast loading
- Responsive: Consider mobile and desktop views

## Placeholder Images

- Add project-related icons or text overlays

1. Export/save images to this folder with appropriate filenames
